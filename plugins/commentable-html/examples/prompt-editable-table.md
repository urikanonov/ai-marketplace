# Example prompt - editable table playground

## Prompt

> Make a commentable HTML discussion table with editable discussion item and owner text, a status
> choice column, and the official editable-table building block. Let reviewers add/remove rows and
> columns, rename columns, sort the view, undo changes and return one cumulative change card through
> Copy all. Explain browser-local saving versus exporting a standalone HTML. Use generic example
> discussion items and include a normally commentable paragraph nearby.

## What you get

A standalone discussion-table playground with text and choice cells, row and column controls,
Undo/Redo, one cumulative change card and a nearby paragraph for ordinary review comments.
